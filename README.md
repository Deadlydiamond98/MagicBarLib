<h1 align="center">Koala Lib</h1>
<p align="center">
Koala Lib (Originally known as Magic Bar Lib) is a fabric library mod that adds various things that I've found myself using in my mods, or things I've found to potentially be helpful for mods. I plan to continue working on it and add more things as I go. Features Include a Config System, Togglable Magic Meter, "Physics Projectiles", and more customizable forms of vanilla Items like Shields and Bundles.
</p>
